# pickstream

Pick digests and stream fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/pickstream/

## Install / run

```bash
git clone https://github.com/theworker02/pickstream.git
cd pickstream
node src/cli.js
node --test
```
